# Ahmed Alaa's Portfolio

بورتفوليو عربي وإنجليزي جاهز للنشر على **GitHub Pages**. الملفات المنشورة جاهزة بالفعل؛ لا تحتاج إلى تشغيل أوامر بناء للحصول على الرابط لأول مرة.

## الحصول على رابط للموقع

1. فك ضغط `Ahmed Alaa's Portfolio.zip` وافتح المجلد الموجود بداخله.
2. من حسابك على [GitHub](https://github.com/new)، أنشئ مستودعًا باسم `ahmed-alaa-portfolio`. اختر **Public** إذا كنت تستخدم GitHub Free.
3. اختر **Add file → Upload files** وارفع **محتويات المجلد** كما هي، ثم اضغط **Commit changes**. ارفع الملفات والمجلدات الموجودة داخل المجلد، وليس ملف ZIP أو المجلد الخارجي نفسه. يجب أن يكون `index.html` بجوار مجلد `assets` مباشرة في جذر المستودع. احتفظ بملف `.nojekyll` أيضًا.
4. افتح **Settings → Pages**.
5. ضمن **Build and deployment**، اختر **Deploy from a branch**، ثم الفرع **main** والمجلد **/(root)**، واضغط **Save**.
6. بعد انتهاء النشر، سيظهر رابط الموقع في صفحة **Pages** مع زر **Visit site**.

شكل الرابط عند استخدام اسم المستودع المقترح:

```text
https://YOUR-USERNAME.github.io/ahmed-alaa-portfolio/
```

استبدل `YOUR-USERNAME` باسم حسابك على GitHub. إذا غيّرت اسم المستودع، سيظهر اسمه في الرابط بدلًا من `ahmed-alaa-portfolio`.

مرجع إعداد النشر: [توثيق GitHub Pages الرسمي](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## الملفات

| الملف أو المجلد | الاستخدام |
| --- | --- |
| `index.html` | الصفحة الجاهزة للنشر، وتتضمن المحتوى العربي الأساسي |
| `assets/` | الصور المعروضة، لقطات البرامج المحجوبة، الـCV، الخطوط، ملفات التصميم والتفاعل |
| `favicon.svg` | أيقونة الموقع |
| `.nojekyll` | إعداد نشر الملفات الثابتة كما هي |
| `source/` | الكود القابل للتعديل ومحتوى النسختين العربية والإنجليزية |
| `scripts/` | أوامر إعادة البناء والمعاينة المحلية |
| `package.json`، `vite.config.ts`، `tsconfig.json` | إعدادات إعادة بناء الموقع عند تحديثه |

## المعاينة على جهازك

ثبّت **Node.js 22.13 أو أحدث**، ثم افتح Terminal داخل المجلد وشغّل:

```bash
npm run preview
```

افتح `http://127.0.0.1:4173`. لا تحتاج إلى تثبيت مكتبات الموقع لتشغيل هذه المعاينة، لأن الملفات جاهزة بالفعل. افتح الموقع عبر هذا الرابط بدلًا من النقر مباشرة على `index.html`.

## تحديث المحتوى لاحقًا

- عدّل النبذة والخبرات والمهارات والكورسات وبيانات التواصل داخل `source/content.ts`. حدّث الحقلين `ar` و`en` للمعلومة نفسها.
- عدّل قائمة لقطات المشاريع وعناوينها داخل `source/gallery.json`، وضع الصور الجديدة داخل `assets/`. استخدم مسارات مثل `./assets/image.webp`، وحدد المشروع وأبعاد الصورة وعنوانها باللغتين.
- يمكن استبدال ملف `assets/Ahmed-Alaa-CV.pdf` بملف CV جديد بالاسم نفسه ورفعه مباشرة، دون إعادة بناء.
- تخطيط الأقسام ومعرض الصور داخل `source/page.tsx`، والتنسيق داخل `source/globals.css`.
- افحص أي لقطة جديدة واحجب المعلومات الشخصية أو الداخلية قبل إضافتها إلى `assets/` أو GitHub. الصور المرفقة في هذه الحزمة هي النسخ المعدّة للعرض.

بعد تعديل الكود أو النصوص أو قائمة الصور، شغّل:

```bash
npm install
npm run check
npm run build
npm run preview
```

سيحدّث أمر البناء `index.html` وملفات `assets` الخاصة بالتنسيق والتفاعل تلقائيًا. ارفع الملفات المحدثة والكود إلى المستودع؛ ستنشر GitHub Pages التحديثات من الفرع نفسه. لا ترفع `node_modules` أو مجلدات البناء المؤقتة.

## خصائص الموقع

العربية هي اللغة الافتراضية، ويُحفظ اختيار اللغة للزيارات التالية. زر **العربية | English** ظاهر على الهاتف والكمبيوتر، مع اتجاه RTL/LTR حسب اللغة. تفاصيل المشاريع ومعرض الصور تبقى مفتوحة عند التبديل، ويتيح المعرض التكبير والتنقل بين الصور. تستخدم الحزمة مسارات نسبية لتعمل مع رابط مستودع GitHub Pages أو نطاق مخصص.
